# Rewind Bar POS – webversie

Openen op de iPhone: **https://kolenschuur.github.io/rewind-bar/** in Safari → Deel → Zet op beginscherm.

Deze repo bevat alleen de webbestanden. Alle verkopen en codes blijven op het toestel zelf; er wordt niets naar deze site of een server gestuurd. De broncode en de Android-app staan in de privé-repo `rewind-bar-pos`.
